# Direction: Engineering field notes
Audience: hiring managers and technical reviewers. Job: understand four projects, try their demos and inspect proof.
An editorial, warm paper surface with ink typography, cobalt links and a restrained burnt orange index. Large project titles, real interface captures and annotated decisions carry the page. No stock imagery, fake statistics, client claims or decorative gradient art.
References: the actual Analyzer source comparison, Intake inbox, Closeout evidence board and Azure saved data replay. Their media remains labeled by scope.
Tokens: system sans for UI; Georgia for the editorial headline; system monospace for indices. Fixed type sizes by breakpoint, not viewport scaled fonts. Base spacing 8px. Radius 4px. Hairline rules, no card shadows. Focus outline 3px. Native details and video controls; reduced motion respected.
Privacy: no analytics, cookies, form, contact email, phone or external font. Contact points to public GitHub profile. Printable project résumé has only public project information.
